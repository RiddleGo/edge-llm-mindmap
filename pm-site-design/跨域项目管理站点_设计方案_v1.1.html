0. 设计决策摘要

  1. 不做通用项目管理平台。做成跨域测试的领域站点：车型软件包与版本节点为轴，影响面变成可跟踪的回归任务。
  2. 技术形态：原生 HTML/CSS/JS 单文件 + Python 标准库 HTTP 服务 + JSON 原子写。不为美化引入 React / Tailwind / Motion。
  3. 导航：4 个工作区；原 12 个 hash 全部保留为别名。
  4. 不上缺陷管理系统。DTS 单只作为周报的只读快照输入。
  5. 周报预留： 事实表由站点汇总，模型只写草稿；Key 只进服务端环境变量。未配置则功能隐藏或显示占位，不访问外网。
  6. 视觉方向 C：品牌红只用于 logo、每屏一个主按钮、逾期/失败。

3. 导航预留

协同工作区别名增加 #weekly（预留）。未启用时：

  • 若有人打开旧书签 #weekly：展示占位页，文案固定为「周报功能预留，配置后启用」，提供返回 #tasks 的链接。不报 JS 错，不请求模型。

启用后（见 4.18.8）芯片出现，文案锁定：周报。

4.18 周报起草（预留）

产品结论：要这个功能，但先占位，以后打开。

4.18.1 以后启用时用户能做什么

  1. 选自然周（默认本周一至周日，最长 14 天）。
  2. 预览三块事实表（不调模型也能看）：

- 测试任务：创建 / 关闭 / 进行中、完成度、逾期。
- 版本计划：已到期、未来 7 天、有无任务覆盖。
- DTS：来自导入快照的新增 / 关闭 / 超期未关（无快照则该节写「未导入」）。

  1. PIN 后「生成周报草稿」：服务端固化事实 JSON，再调模型，返回 Markdown。
  2. 人改完 → 复制 → 可选存档。
  3. 无 Key：只导出事实骨架，固定标题，叙述留空。

4.18.2 数据来源（以后也不做 DTS 系统）

来源以后如何接入不做
测试任务tasks.json—
版本计划带 ts 的节点—
DTS导入 dts_snapshot.json不爬缺陷系统、不改单

DTS 最小字段：id, title, status, severity, created, closed, car, feature, owner。缺列显示「—」。

4.18.3 预留的环境变量（现在不要配也可以）

变量用途未设置时
LLM_API_KEY模型密钥周报保持关闭或仅骨架
LLM_BASE_URLOpenAI 兼容网关可空
LLM_MODEL模型名可空
LLM_REDACT1 时姓名替换为负责人 A/B默认不脱敏
TASK_PIN生成 / 导入 DTS / 存档未配则写接口 503

全部只存在于服务器进程环境。禁止写入 index.html、仓库、周报存档、日志。

启用口令（实现时）：WEEKLY_ENABLED=1 且 已配置 PIN。仅有 Key 没有该开关也不露出入口——方便以后「再用起来」时只改环境变量并重启服务。

推荐以后打开顺序：先 WEEKLY_ENABLED=1 只出事实表 → 再配内网 LLM_* → 最后才考虑公网网关（页上必须有出域提示）。

4.18.4 预留接口名（实现前不要占用这些路径做别的事）

路径方法鉴权以后职责
/api/weekly-factsGET—事实 JSON
/api/weekly-generatePOSTPIN调模型或返回骨架
/api/weekly-dtsGET/POSTPOST 需 PIN快照
/api/weekly-savePOSTPIN存档，最多 52 份
/api/weekly-listGET—历史周

现网若尚无这些路径：保持 404 即可。前端未启用时不要轮询。

4.18.5 以后正文结构（契约，实现时不要改标题）

  1. 本周结论
  2. 测试任务
  3. 版本节点
  4. DTS 问题单
  5. 下周关注

数字以事实表为准，模型不得编造单号和百分比。

4.18.6 明确现在不做

  • 不接真实 API Key、不把 Key 交给前端。
  • 不做聊天气泡、思考链、流式打字。
  • 不爬 DTS。
  • 不把周报做成 P0。打开属于 P2，且排在任务闭环与 PIN 环境变量之后。

4.18.7 以后启用检查清单

  1. TASK_PIN 已迁出源码，改为环境变量。
  2. 服务端增加 /api/weekly-status 与 facts 预览（仍可不调模型）。
  3. WEEKLY_ENABLED=1，协同区出现「周报」，#weekly 可预览事实。
  4. 导入一版 DTS 快照（可空）。
  5. 配置内网 LLM_BASE_URL + LLM_API_KEY + LLM_MODEL。
  6. 用 PIN 生成一页草稿，核对事实表与正文数字一致。
  7. 回归：旧 15 个 API、12 个原 hash、按钮文案不变；index.html 中搜不到 Key。

4.18.8 前端占位约定（若以后改 template，也先只做这一层）

WEEKLY_ENABLED != 1  → 隐藏芯片；#weekly 占位文案；零网络
WEEKLY_ENABLED == 1 且无 Key → 芯片可见；事实表 +「导出事实表」
WEEKLY_ENABLED == 1 且有 Key → 主按钮「生成周报草稿」

占位页不新增依赖。

9. 安全（与周报预留有关）

  • 密钥与 PIN 同事级：环境变量，日志只记 OK/FAIL。
  • 公网模型 = 数据出域；默认假设未启用。
  • 周报 POST 体以后可放宽到 256KB，仅限 /api/weekly-*。

12. 演进（周报位置）
